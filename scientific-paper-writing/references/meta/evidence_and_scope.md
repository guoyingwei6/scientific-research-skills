# 证据边界与编辑范围

> 吸收自 ZZD academic skill 1.4.0 与其 humanizer 3.4.3 的写作治理规则（2026-11-09 审阅），按本 skill 的组学写作场景改写。凡是改动用户文字的任务都加载本文件。

---

## 编辑范围梯度

先按用户措辞判断授权范围，再动手。用户的具体指令优先。

| 用户说法 | 允许做的 | 不允许做的 |
|---|---|---|
| 校对 / proofread | 改明确的拼写、语法、标点、一致性错误 | 改句式和结构 |
| 润色 / polish | 改措辞、句序、衔接和节奏；可拆并句子 | 改段落功能、删实质内容；篇幅应接近原文 |
| 改写 / 去 AI 味 | 重组句子和段落 | 删掉任何独立事实、判断、限定、例子或逻辑关系；把改写变成摘要 |
| 重构 / 调整结构 | 在指定范围内重组论证和章节 | 静默改变科学解释（须单独标出） |
| 压缩 / 缩写 | 删到指定长度 | 删掉核心结论、决定性证据和实质局限（删了要说明） |
| 只看看 / 诊断 | 引原句、说问题和优先级 | 未经要求交付改写稿 |

仅润色一段时，不顺手扩展成研究设计建议或全文重构；用户说“只给终稿”就只给终稿。

## 必须原样保护的内容

名称、数字、单位、日期、排序、不确定性、否定、条件、时间顺序、引用及其覆盖范围、样本层级与分母、基因符号、软件版本、公式、代码、文件路径。合并句子时，引用跟着它支撑的 claim 走，不能因合并而扩大支撑范围。

保留合理的 hedging 和不利结果。删掉多余的防御性措辞，但不删掉背后的局限本身。

## 证据类型不可混写

写作和润色时逐句确认 claim 属于哪一类，措辞强度按 `over_claim_guard.md` 的词梯匹配：

| 证据类型 | 典型来源 | 可用措辞上限 |
|---|---|---|
| 本研究观察 | 用户真实结果、表格、日志 | identify / find / reveal |
| 统计关联 | GWAS、GEA、FST/XP-EHH 离群 | be associated with / suggest |
| 位置重叠 | 共定位、候选区间与已知 QTL 重叠 | overlap / be consistent with（共定位不是中介证明） |
| 模型预测 | 品种鉴定分类器、功能预测、模拟 | predict / indicate（预测不是功能验证） |
| 文献观察 | 直接核查过的已发表研究 | 按原文强度转述，不加码 |
| 实验因果 | 敲除、功能实验 | demonstrate |
| 假设与拟开展工作 | 推测、future work | may / could / we propose |

固定物种、参考基因组版本、坐标、等位基因方向、组织、个体与文库层级、比较组和多重检验范围；同一稿件内不能前后漂移。未知信息保持未知，阴性、相反和不确定证据不删。

纯语言修改不能静默改变结论强度。发现科学解读问题时，在修改说明里单独用 `[需要确认: ...]` 标出，并给一个有边界的替代表述。

## 新写前先查文献

- 新写 Introduction、Discussion 或实质性扩展论证前，先查 Zotero，再按需要补 PubMed 和 bioRxiv；读最相关工作的问题、方法、证据和局限后再起草。
- 预印本标明状态，并查是否已有正式版本。
- 普通润色复用已核实来源，不逐句重新检索；新增 claim 或存疑的专业搭配才补查。
- 搜索摘要、标题和记忆里的“大概是某某 2018”不能代替原文核查；查不到就标 `[CITATION NEEDED]`。
- 表达参考近十年相关领域高水平论文的范式，不拼接或复制原句。

## 一次整合编辑与终稿核查

语言、AI 痕迹、over-claim 在同一次编辑里处理，不做“先改一轮再打分再改一轮”的循环，也不虚构独立审稿人。

交付前把终稿与原文逐段对照一次：

1. 数字、单位、引用、基因名和限定词是否全部保留；
2. 每个 claim 的强度是否与证据类型一致；
3. 是否越出了用户授权的编辑范围；
4. 若交付的是文件（docx、PDF、LaTeX），重新打开最终文件检查内容和版面，不以脚本退出成功代替检查。

没做的核查（例如没查原文、没编译 LaTeX）在说明里如实写出。
