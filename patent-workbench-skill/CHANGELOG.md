# CHANGELOG

记录 `patent-workbench-skill` skill 的版本演进。公开名称为“专利工作台 Skill”。颗粒度按功能模块级更新为单位，不按 commit 级；不删除历史版本块。

## v2.0.0 — 2026-06-22（更名为专利工作台 Skill + 新增审查意见答复辅助模式）

### 重大变更

- **公开定位从"专利挖掘 + 交底书"扩展为"专利工作台 Skill"**，覆盖专利申请准备与审查意见答复辅助阶段的三大并列工作模式：
  - A. 交底书生成（原主流程 8 步）
  - B. 交底书迭代（原迭代模式）
  - C. 审查意见答复辅助草拟 / OA 辅助（**本次新增**）
- `name` 从 `patent-disclosure-desktop` 调整为 `patent-workbench-skill`；仓库目录从 `patent-disclosure-desktop/` 调整为 `patent-workbench-skill/`，与公开名称保持一致。
- 平台定位从“Claude Desktop macOS 版”调整为“跨 Agent 适配”：Claude Desktop、Codex、Windows/macOS/Linux 上具备文件读取、联网检索、文档写入能力的 Agent 均可使用；Desktop Commander 仅作为 Claude Desktop 的可选增强工具。
- 文件头新增「工作模式总览」表，按用户所持材料（项目材料 / 已有草稿 / 官方通知书 + 对比文件）自动分流；模式 C 不走交底书 1–8 步。
- `description` 与触发词扩展：纳入「审查意见 / 一通 / 二通 / OA / 意见陈述书 / 补正 / 对比文件 / 驳回 / 答复审查员」等，新增简短指令 `/oa`、`/审查意见`、`/答复`。
- 新增「专利实务边界」和「正式依据与引用边界」：明确本 skill 只做技术材料梳理和文本草拟辅助，不构成法律意见、专利代理意见或授权/驳回结果预测。

### 新增内容

| 区块 | 说明 |
|---|---|
| 「创造性论证方法论」节（A/C 共用） | 判断"相当于"的四层退守法（技术领域 → 技术特征 → 技术问题 → 技术效果）；结合启示 / 发明构思（应对"对比文件 1+2 结合"）；三类常见套路反制（隐含公开 / 公知常识 / 文件结合） |
| 「审查意见答复辅助草拟模式（模式 C）」 | C0 材料收集 → C1 区分补正 / 实质通知书 → C2 实质答复（1 套 1 秘 3 原则）→ C3 答复书草稿产出与自检；含《意见陈述书》结构与权利要求修改规范（专利法第三十三条） |

### 既有章节增强（把日后答复的"弹药"前置到交底书阶段）

- **Step 3**：候选专利点新增「创造性储备」字段——挖点时即标注 2–3 个暂不入独权、留作日后修改权利要求的次级特征。
- **Step 5 / 3.5 节**：区别技术特征分析从单句"未公开 / 未解决"升级为四层逐层论证；多对比文件时补「结合启示」论述。
- **实施例**：新增 4.3「备用技术细节（创造性储备）」，为日后修改权利要求预留空间，并提示不得超出原说明书和权利要求书记载范围。
- **Agent 执行检查清单**：补充模式 C 检查项（区分通知书类型、亲读对比文件全文、四层核查、修改不超范围、不替用户向国知局提交）。
- **风险表述降级**：将“降低驳回风险的核心手段”“审查员就应再给一次机会”等确定性表述，改为“常见修改策略”“通常有助于争取继续审查机会”，并要求所有草稿由申请人/代理人复核后再提交。

### 正式依据与范式来源

| 来源 | 吸收到 |
|---|---|
| 《中华人民共和国专利法》第二十二条 | 新颖性、创造性、实用性判断框架；创造性论述中的“突出的实质性特点和显著的进步”。 |
| 《中华人民共和国专利法》第二十六条 | 说明书公开充分、权利要求清楚并以说明书为依据的边界。 |
| 《中华人民共和国专利法》第三十三条 | OA 阶段权利要求修改不得超出原说明书和权利要求书记载范围。 |
| 《专利审查指南》 | 创造性判断、实质审查程序、审查意见答复和修改文本核查等操作性规则；具体条文以现行最新版为准。 |
| 知乎「海绵叔叔」答复审查意见经验（1 套 1 秘 3 原则、判断"相当于" abcd 四步法） | 仅作为答复组织方法启发，不作为法律依据。 |
| 知乎「度老湿」审查员视角四套路应对（隐含公开举反例、公知常识举证、结合启示 / 发明构思） | 仅作为答复组织方法启发，不作为法律依据。 |

## v1.0.0 — 2026-06-12（初版，移植）

从原版 [handsomestWei/patent-disclosure-skill](https://github.com/handsomestWei/patent-disclosure-skill) 移植改编，初版主要面向 Claude Desktop 使用场景：

- 覆盖专利挖掘 + 技术交底书生成全流程（8 步主流程 + 迭代模式）。
- 工具按优先级自动降级（Desktop Commander / web_search / Word MCP）。
- 国知局 epub.cnipa.gov.cn 优先查新，Google Patents 补充。

## 维护原则

1. 每次功能模块级更新写一个版本块（v2.1.0、v2.2.0 …），列清楚改了什么、为什么改、范式来源。
2. **不删除历史版本块**——即使某做法被推翻，也保留记录说明原因。
3. 版本号语义：新增模式 / 架构级变更 → major；模式内能力增强 → minor；措辞或小修订 → patch。
